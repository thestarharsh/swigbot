# Start

> Pick your path - developer, enterprise, or AI-client consumer.

Three paths in, one platform. Pick the one that matches what you're building.

  
  
  

## Not sure which?

- If you're **writing code** that calls an LLM and want Swiggy as a tool in that agent → **Developer**.
- If you **operate an agent platform** that your users interact with (voice assistant, in-app agent, chat UI) and need to broker Swiggy on their behalf → **Enterprise**.
- If you're a **user of an existing AI client** (Claude, ChatGPT) and just want Swiggy available inside it → **Consumer**.
- Still unsure - read [What is Swiggy MCP?](/docs/start/what-is-swiggy-mcp.md) for the primer.
